Whisper: i vocali diventano testo sul tuo PC

La guida breve del video · English below

Dai a Whisper un file audio e ti restituisce il testo. Gira sul tuo PC: l'audio non esce dal computer.

Prima ti servono: Python (da python.org) e ffmpeg, il programma che legge i file audio.

  1. Apri PowerShell e installa ffmpeg: 
    winget install Gyan.FFmpeg
    Poi chiudi e riapri PowerShell.
  2. Installa Whisper: 
    pip install -U openai-whisper
  3. Trascrivi un file (mettiti nella cartella dove si trova): 
    whisper vocale.mp3 --language Italian

Accanto al file trovi il testo (.txt) e i sottotitoli (.srt). La prima volta scarica il modello, circa 1,5 GB. Senza scheda video funziona lo stesso, più piano: per fare prima aggiungi --model small.

Il progetto: github.com/openai/whisper

Whisper: voice messages into text on your PC

Give Whisper an audio file and it gives you the text. It runs on your PC: the audio never leaves your computer.

You need first: Python (from python.org) and ffmpeg, the tool that reads audio files.

  1. Open PowerShell and install ffmpeg: 
    winget install Gyan.FFmpeg
    Then close and reopen PowerShell.
  2. Install Whisper: 
    pip install -U openai-whisper
  3. Transcribe a file (from the folder where it is): 
    whisper voice.mp3

Next to the file you get the text (.txt) and the subtitles (.srt). The first run downloads the model, about 1.5 GB. It works without a graphics card too, just slower: add --model small to speed it up.

The project: github.com/openai/whisper
